## Cara Melihat Report

1. Pilih folder tanggal yang ingin dilihat
2. Buka folder `target/site/serenity/`
3. Buka file `index.html` di browser

Atau langsung navigate ke path:
```
<folder-tanggal>/target/site/serenity/index.html
```
